# 附录 C　术语对照

书里出现的主要术语，按中文拼音顺序排列，给出英文对应词和一句话解释。

- **贝尔态**（Bell state）　两比特最大纠缠态的四个正交基，用 $|\Phi^\pm\rangle$ 与 $|\Psi^\pm\rangle$ 表示。
- **布洛赫球**（Bloch sphere）　单比特纯态的可视化表示，球面上的点对应所有可能的纯态。
- **超导量子比特**（superconducting qubit）　用约瑟夫森结构成的电路，工作在毫开尔文温度，用微波操控。
- **电荷噪声**（charge noise）　环境中的电荷涨落，是库珀对盒退相干的主要来源。
- **非谐性**（anharmonicity）　超导比特相邻能级间距的差值，决定能否单独寻址前两个能级。
- **光子数态**（Fock state，number state）　光子数完全确定的量子态。
- **哈达玛门**（Hadamard gate）　把基态变成等权叠加的单比特门，量子线路里最常用。
- **纠错码**（error-correcting code）　把逻辑比特编码到多个物理比特上以容忍错误的方法。
- **量子比特**（qubit）　两能级量子系统，量子信息的基本单元。
- **量子点**（quantum dot）　半导体中的纳米结构，可以束缚单个电子或者产生单光子。
- **量子傅里叶变换**（quantum Fourier transform）　离散傅里叶变换的量子版本，复杂度随比特数多项式增长。
- **量子密钥分发**（quantum key distribution）　利用量子力学原理分发密钥的协议，代表是 BB84。
- **量子优越性**（quantum supremacy）　在某个特定任务上用量子设备超越最强的经典计算机。
- **里德堡态**（Rydberg state）　主量子数很大的激发态，偶极矩大，相互作用强。
- **离子阱**（ion trap）　用电磁场束缚离子的装置，量子比特编码在离子的内态上。
- **密度矩阵**（density matrix）　描述混合态的数学工具，也叫密度算符。
- **退相干**（decoherence）　系统与环境的纠缠导致相干性丧失的过程。
- **退相位**（dephasing）　相位随机漂移导致叠加态变成混合态，不涉及能量交换。
- **稳定子**（stabilizer）　一组对易的泡利算符，其共同本征空间定义了纠错码。
- **无克隆定理**（no-cloning theorem）　不存在复制任意未知量子态的幺正操作。
- **相干态**（coherent state）　湮灭算符的本征态，最接近经典激光的量子态。
- **约瑟夫森结**（Josephson junction）　两块超导体夹一层薄绝缘层，是超导量子比特的核心元件。
- **张量积**（tensor product）　把两个子系统拼成复合系统的数学运算。
- **缀饰态**（dressed state）　光与原子强耦合后的本征态，是裸态的线性组合。

个别术语在不同文献里有不同译法，比如 decoherence 也译作“消相干”，qubit 也译作“量子位”，遇到时按上下文判断即可。
