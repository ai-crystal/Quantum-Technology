# 后记

写完这本书，最强烈的感受是，量子通信的难点几乎都不在量子力学。

不可克隆、测量扰动、纠缠交换，这些概念在纸上都干净利落，一页纸就能讲完。真正耗掉几十年的是别的东西。激光器不是单光子源，探测器会被强光照晕，光纤每公里吃掉零点二分贝，卫星九十分钟才转一圈，只给你几分钟的窗口。

每一次进步都是跟这些琐碎的东西搏斗的结果。诱骗态是一组联立方程，双场协议是一次干涉相位的稳定，京沪干线是三十多个机房的运维。论文里的一句话，工程上可能是十年的活。

书里也尽量没有把量子密钥分发写成万能药。它需要认证，需要专用链路，需要信任某些环节。它解决的是密钥分发，不是通信的全部。同样，后量子密码也不是过渡方案，它大概率会长期存在，因为它的部署成本低得多。

两条路会一起走下去。一条把物理定律变成安全，一条把新的数学难题变成安全。它们的分工，到头来会由成本和场景决定，而不是由哪个更优雅决定。
