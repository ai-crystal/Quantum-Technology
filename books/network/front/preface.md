# 前言

保密通信的麻烦，说到底只有一句话，中间人听得见。

为了解决这句话，人类试过很多办法。把信使杀了灭口，把纸条吞进肚子，把字母换成符号。这些办法管用了几千年，直到电报和无线电出现，线路不再属于某个人，谁都能在线上搭一个线圈。

二十世纪给出的答案是数学。迪菲和赫尔曼把锁分成两把，一把公开，一把自留，于是两个从没见过面的人也能在众目睽睽之下商量出一把密钥。这套办法撑起了今天的互联网，也把一个隐患埋在了地基里。它的安全性依赖于某个数学问题没人算得出来，而这件事没人能证明。

量子力学给了另一个答案。它不说某道题难，它说有些事在原理上做不到。一个未知的量子态不能被复制，一次窃听必然留下痕迹。这两条把密钥分发变成了一个物理问题，安全性不再依赖计算能力的假设。

这本书讲的就是这条路。从一个协议开始，讲到实际系统的漏洞，讲到距离带来的困难，讲到网络，再往后是另一条并行的路，用量子计算机也解不动的数学难题把锁换掉。两条路各有各的边界，书里没有替读者选边，只把边界画清楚。

这条路上有很漂亮的想法，也有很多难看的妥协。诱骗态是为了绕开不完美的光源，可信中继是为了绕开光纤的损耗，混合部署是为了在标准还没稳的时候不至于把系统跑挂。这些妥协写进书里，因为它们才是真实的技术。
