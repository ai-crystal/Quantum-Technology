# 量子学技术

> 从光的直觉到量子机器　·　作者 Dr. Dezeming

量子技术听起来遥远，其实它的每一条规则都来自可以重复的实验。这本书从一盏灯发出的光讲起，经过黑体辐射、光电效应、双缝干涉、原子光谱和激光，一路讲到量子比特、量子线路、超导芯片和量子纠错。

全书分三篇。

**第一篇 直觉与图像**，几乎不写公式，用实验和图像把量子世界的规矩讲清楚。读完能看懂科普文章里的叠加、测量、不确定性和纠缠。

**第二篇 语言与规则**，换成向量和矩阵，把同一批现象重新写一遍。读完能读懂教材里的推导，能自己算一些简单的量子态和门。

**第三篇 器件与工程**，进入真实的机器，讲噪声、退相干、腔电动力学、超导与离子阱、光量子芯片、纠错和通信。读完能跟上这个领域论文里的讨论。
